Gitsync.md Android पर असली Git वर्कफ़्लो लाता है। GitHub कनेक्ट करें, रिपॉज़िटरी को ऐप स्टोरेज में क्लोन करें, बदलाव देखें, और अपने फ़ोन से कोड या markdown सुरक्षित रूप से सिंक करें।

असली रिपॉज़िटरी के लिए बना
- OAuth या पर्सनल एक्सेस टोकन से साइन इन करने के बाद GitHub रिपॉज़िटरी ब्राउज़ करें
- प्रोजेक्ट सीधे Android ऐप स्टोरेज में क्लोन करें
- सिस्टम git बाइनरी के बिना Git ऑपरेशन चलाएँ

भरोसे के साथ सिंक करें
- branch, क्लीन या डर्टी स्थिति, staged फ़ाइलें और untracked फ़ाइलें देखें
- रिपॉज़िटरी की स्थिति जाँचने के बाद सुरक्षित रूप से pull करें
- बदलाव हटाने या commit करने से पहले लाइन-दर-लाइन diff देखें
- लोकल बदलावों को commit करें और अपने remote पर push करें

लोकल Git टूलकिट
- अलग-अलग फ़ाइलों को stage और unstage करें
- branch बनाएँ, स्विच करें, merge करें और डिलीट करें
- ours, theirs या मैन्युअल विकल्प से conflict सुलझाएँ
- हिस्ट्री देखें, stash बनाएँ और वापस पाएँ, और tags मैनेज करें

मोबाइल के लिए डिज़ाइन किया गया
- तेज़ Jetpack Compose इंटरफ़ेस
- डार्क और लाइट मोड
- Android संगतता के लिए ऐप-स्टोरेज में क्लोन लोकेशन
- मुफ़्त डाउनलोड, Google Play के ज़रिए एक बार की Full Access इन-ऐप खरीदारी के साथ
- कोई विज्ञापन नहीं और कोई सब्सक्रिप्शन नहीं

Gitsync.md डेवलपर्स, लेखकों और Android पर GitHub-आधारित फ़ाइलें मैनेज करने वाले हर व्यक्ति के लिए बना है। प्राइवेट रिपॉज़िटरी के लिए GitHub से साइन इन करें या पर्सनल एक्सेस टोकन दें। टोकन आपके डिवाइस पर लोकल रूप से सेव किए जाते हैं।
