Gitsync.md 将真正的 Git 工作流带到 Android。连接 GitHub，将仓库克隆到应用存储中，查看更改，并在手机上安全同步代码或 markdown。

为真实仓库打造
- 通过 OAuth 或个人访问令牌登录后浏览 GitHub 仓库
- 将项目直接克隆到 Android 应用存储
- 无需系统 git 二进制文件即可执行 Git 操作

放心同步
- 查看分支、干净或有改动状态、已暂存文件和未跟踪文件
- 检查仓库状态后安全拉取
- 在丢弃或提交更改前逐行查看 diff
- 提交本地更改并推送到远程仓库

本地 Git 工具箱
- 暂存和取消暂存单个文件
- 创建、切换、合并和删除分支
- 使用 ours、theirs 或手动选择解决冲突
- 查看历史记录、创建和恢复 stash、管理标签

为移动端设计
- 快速的 Jetpack Compose 界面
- 深色和浅色模式
- 使用应用存储作为克隆位置，确保 Android 兼容性
- 免费下载，通过 Google Play 一次性应用内购买解锁完整功能
- 无广告，无订阅

Gitsync.md 专为开发者、写作者以及在 Android 上管理 GitHub 托管文件的所有人打造。对于私有仓库，请使用 GitHub 登录或提供个人访问令牌。令牌仅存储在你的设备本地。
