Gitsync.md מביא תהליכי עבודה אמיתיים של Git ל-Android. התחברו ל-GitHub, שכפלו מאגרים לאחסון האפליקציה, בדקו שינויים וסנכרנו קוד או קובצי markdown בבטחה מהטלפון.

נבנה למאגרים אמיתיים
- עיון במאגרי GitHub לאחר התחברות באמצעות OAuth או אסימון גישה אישי
- שכפול פרויקטים ישירות לאחסון האפליקציה ב-Android
- הרצת פעולות Git ללא צורך בקובץ git בינארי של המערכת

סנכרון בביטחון
- צפייה ב-branch, במצב נקי או מלוכלך, בקבצים ב-stage ובקבצים שאינם במעקב
- ביצוע pull בבטחה לאחר בדיקת מצב המאגר
- סקירת diff שורה אחר שורה לפני מחיקת שינויים או ביצוע commit
- ביצוע commit ו-push לשינויים מקומיים בחזרה ל-remote

ערכת כלים מקומית ל-Git
- הוספה והסרה של קבצים בודדים מה-stage
- יצירה, מעבר, מיזוג ומחיקה של branches
- פתרון קונפליקטים עם ours,‏ theirs או בחירה ידנית
- צפייה בהיסטוריה, יצירה ושחזור של stash וניהול tags

מעוצב למובייל
- ממשק מהיר מבוסס Jetpack Compose
- מצב כהה ובהיר
- מיקום שכפול באחסון האפליקציה לתאימות עם Android
- הורדה חינמית עם רכישה חד-פעמית של גישה מלאה באפליקציה דרך Google Play
- ללא פרסומות וללא מינויים

Gitsync.md נבנה למפתחים, לכותבים ולכל מי שמנהל קבצים המגובים ב-GitHub ב-Android. למאגרים פרטיים, התחברו עם GitHub או הזינו אסימון גישה אישי. האסימונים נשמרים באופן מקומי במכשיר שלכם.
