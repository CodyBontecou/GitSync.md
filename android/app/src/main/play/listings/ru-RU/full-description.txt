Gitsync.md переносит полноценную работу с Git на Android. Подключите GitHub, клонируйте репозитории в хранилище приложения, просматривайте изменения и безопасно синхронизируйте код или файлы markdown прямо с телефона.

ДЛЯ НАСТОЯЩИХ РЕПОЗИТОРИЕВ
- Просматривайте репозитории GitHub после входа через OAuth или персональный токен доступа
- Клонируйте проекты прямо в хранилище приложения на Android
- Выполняйте операции Git без системного бинарного файла git

УВЕРЕННАЯ СИНХРОНИЗАЦИЯ
- Видите текущую ветку, чистое или изменённое состояние, проиндексированные и неотслеживаемые файлы
- Безопасно делайте pull после проверки состояния репозитория
- Просматривайте построчный diff перед отменой изменений или коммитом
- Коммитьте и пушьте локальные изменения в удалённый репозиторий

ЛОКАЛЬНЫЙ НАБОР ИНСТРУМЕНТОВ GIT
- Добавляйте файлы в индекс и убирайте их из индекса по одному
- Создавайте, переключайте, сливайте и удаляйте ветки
- Разрешайте конфликты, выбирая ours, theirs или вручную
- Просматривайте историю, создавайте и восстанавливайте stash, управляйте тегами

СОЗДАНО ДЛЯ МОБИЛЬНЫХ УСТРОЙСТВ
- Быстрый интерфейс на Jetpack Compose
- Тёмная и светлая тема
- Клонирование в хранилище приложения для совместимости с Android
- Бесплатная загрузка и разовая встроенная покупка полного доступа через Google Play
- Без рекламы и подписок

Gitsync.md создан для разработчиков, авторов и всех, кто работает с файлами на GitHub на Android. Для приватных репозиториев войдите через GitHub или укажите персональный токен доступа. Токены хранятся локально на вашем устройстве.
