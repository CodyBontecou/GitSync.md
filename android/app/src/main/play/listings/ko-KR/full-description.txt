Gitsync.md는 실제 Git 워크플로를 Android로 가져옵니다. GitHub에 연결하고, 저장소를 앱 저장 공간에 클론하고, 변경 사항을 검토하고, 휴대폰에서 코드나 markdown을 안전하게 동기화하세요.

실제 저장소를 위한 설계
- OAuth 또는 개인 액세스 토큰으로 로그인한 후 GitHub 저장소 탐색
- 프로젝트를 Android 앱 저장 공간에 바로 클론
- 시스템 git 바이너리 없이 Git 작업 실행

안심하고 동기화
- 브랜치, 클린/더티 상태, 스테이징된 파일, 추적되지 않는 파일 확인
- 저장소 상태를 확인한 후 안전하게 풀
- 변경 사항을 버리거나 커밋하기 전에 줄 단위 diff 검토
- 로컬 변경 사항을 커밋하고 원격 저장소로 푸시

로컬 Git 도구 모음
- 개별 파일 스테이징 및 스테이징 취소
- 브랜치 생성, 전환, 병합, 삭제
- ours, theirs 또는 수동 선택으로 충돌 해결
- 히스토리 보기, stash 생성 및 복구, 태그 관리

모바일에 맞춘 디자인
- 빠른 Jetpack Compose 인터페이스
- 다크 모드와 라이트 모드
- Android 호환성을 위한 앱 저장 공간 클론 위치
- 무료 다운로드, Google Play를 통한 1회성 전체 이용 인앱 구매
- 광고 없음, 구독 없음

Gitsync.md는 개발자, 작가, 그리고 Android에서 GitHub 기반 파일을 관리하는 모든 사람을 위해 만들어졌습니다. 비공개 저장소의 경우 GitHub로 로그인하거나 개인 액세스 토큰을 입력하세요. 토큰은 기기에 로컬로 저장됩니다.
