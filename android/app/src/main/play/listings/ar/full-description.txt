يقدّم Gitsync.md سير عمل Git حقيقيًا على Android. اربط حساب GitHub، واستنسخ المستودعات إلى مساحة تخزين التطبيق، وافحص التغييرات، وزامن الكود أو ملفات markdown بأمان من هاتفك.

مصمَّم للمستودعات الحقيقية
- تصفّح مستودعات GitHub بعد تسجيل الدخول عبر OAuth أو رمز الوصول الشخصي
- استنسخ المشاريع مباشرةً إلى مساحة تخزين تطبيق Android
- نفّذ عمليات Git دون الحاجة إلى ملف git تنفيذي على النظام

زامن بثقة
- اطّلع على الفرع (branch)، وحالة المستودع نظيفة أو معدّلة، والملفات المجهّزة (staged)، والملفات غير المتتبَّعة
- نفّذ pull بأمان بعد التحقق من حالة المستودع
- راجع الفروقات (diff) سطرًا بسطر قبل تجاهل التغييرات أو تنفيذ commit لها
- نفّذ commit وpush للتغييرات المحلية إلى المستودع البعيد

أدوات Git المحلية
- جهّز الملفات فرديًا (stage) أو ألغِ تجهيزها (unstage)
- أنشئ الفروع وبدّل بينها وادمجها واحذفها
- حُلّ التعارضات باختيار نسختك (ours) أو النسخة الأخرى (theirs) أو يدويًا
- اعرض السجل، وأنشئ عمليات stash واستعدها، وأدِر الوسوم (tags)

مصمَّم للهاتف المحمول
- واجهة سريعة مبنية بـ Jetpack Compose
- الوضع الداكن والفاتح
- موقع استنساخ داخل مساحة تخزين التطبيق للتوافق مع Android
- تنزيل مجاني مع عملية شراء واحدة داخل التطبيق للوصول الكامل عبر Google Play
- بلا إعلانات وبلا اشتراكات

صُمّم Gitsync.md للمطوّرين والكتّاب وكل من يدير ملفات مستندة إلى GitHub على Android. للمستودعات الخاصة، سجّل الدخول باستخدام GitHub أو أدخل رمز وصول شخصيًا. تُخزَّن الرموز محليًا على جهازك.
