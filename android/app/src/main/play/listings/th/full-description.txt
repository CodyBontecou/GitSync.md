Gitsync.md นำเวิร์กโฟลว์ Git ตัวจริงมาสู่ Android เชื่อมต่อ GitHub โคลนรีโพสิทอรีลงในพื้นที่จัดเก็บของแอป ตรวจดูการเปลี่ยนแปลง และซิงค์โค้ดหรือไฟล์ markdown จากโทรศัพท์ได้อย่างปลอดภัย

สร้างมาเพื่อรีโพจริง
- เรียกดูรีโพสิทอรี GitHub หลังลงชื่อเข้าใช้ด้วย OAuth หรือ personal access token
- โคลนโปรเจกต์ลงในพื้นที่จัดเก็บของแอป Android โดยตรง
- ใช้คำสั่ง Git ได้โดยไม่ต้องมีไบนารี git ของระบบ

ซิงค์อย่างมั่นใจ
- ดู branch สถานะสะอาดหรือมีการแก้ไข ไฟล์ที่ stage แล้ว และไฟล์ที่ไม่ได้ติดตาม
- pull อย่างปลอดภัยหลังตรวจสอบสถานะรีโพสิทอรี
- ตรวจดู diff ทีละบรรทัดก่อนทิ้งการเปลี่ยนแปลงหรือ commit
- commit และ push การเปลี่ยนแปลงในเครื่องกลับไปยัง remote

ชุดเครื่องมือ Git ในเครื่อง
- stage และ unstage ไฟล์ทีละไฟล์
- สร้าง สลับ merge และลบ branch
- แก้ conflict ด้วย ours, theirs หรือเลือกเอง
- ดูประวัติ สร้างและกู้คืน stash และจัดการ tag

ออกแบบมาเพื่อมือถือ
- อินเทอร์เฟซ Jetpack Compose ที่รวดเร็ว
- โหมดมืดและโหมดสว่าง
- ตำแหน่งโคลนในพื้นที่จัดเก็บของแอปเพื่อความเข้ากันได้กับ Android
- ดาวน์โหลดฟรี พร้อมการซื้อในแอปแบบครั้งเดียวสำหรับ Full Access ผ่าน Google Play
- ไม่มีโฆษณาและไม่มีการสมัครสมาชิก

Gitsync.md สร้างมาสำหรับนักพัฒนา นักเขียน และทุกคนที่จัดการไฟล์ที่อยู่บน GitHub ผ่าน Android สำหรับรีโพสิทอรีส่วนตัว ให้ลงชื่อเข้าใช้ด้วย GitHub หรือใส่ personal access token โทเค็นจะถูกจัดเก็บไว้ในอุปกรณ์ของคุณเท่านั้น
