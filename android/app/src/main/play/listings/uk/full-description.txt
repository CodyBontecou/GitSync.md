Gitsync.md переносить повноцінну роботу з Git на Android. Підключіть GitHub, клонуйте репозиторії до сховища застосунку, переглядайте зміни та безпечно синхронізуйте код або файли markdown просто з телефона.

ДЛЯ СПРАВЖНІХ РЕПОЗИТОРІЇВ
- Переглядайте репозиторії GitHub після входу через OAuth або персональний токен доступу
- Клонуйте проєкти безпосередньо до сховища застосунку на Android
- Виконуйте операції Git без системного бінарного файлу git

ВПЕВНЕНА СИНХРОНІЗАЦІЯ
- Бачте поточну гілку, чистий чи змінений стан, проіндексовані та невідстежувані файли
- Безпечно робіть pull після перевірки стану репозиторію
- Переглядайте порядковий diff перед скасуванням змін або комітом
- Комітьте та пуште локальні зміни до віддаленого репозиторію

ЛОКАЛЬНИЙ НАБІР ІНСТРУМЕНТІВ GIT
- Додавайте файли до індексу та вилучайте їх з індексу поодинці
- Створюйте, перемикайте, зливайте та видаляйте гілки
- Розв'язуйте конфлікти, обираючи ours, theirs або вручну
- Переглядайте історію, створюйте та відновлюйте stash, керуйте тегами

СТВОРЕНО ДЛЯ МОБІЛЬНИХ ПРИСТРОЇВ
- Швидкий інтерфейс на Jetpack Compose
- Темна та світла тема
- Клонування до сховища застосунку для сумісності з Android
- Безкоштовне завантаження та одноразова вбудована покупка повного доступу через Google Play
- Без реклами та підписок

Gitsync.md створено для розробників, авторів і всіх, хто працює з файлами на GitHub на Android. Для приватних репозиторіїв увійдіть через GitHub або вкажіть персональний токен доступу. Токени зберігаються локально на вашому пристрої.
