Gitsync.md 將真正的 Git 工作流程帶到 Android。連結 GitHub，將儲存庫複製到 App 儲存空間，檢視變更，並在手機上安全同步程式碼或 markdown。

為真實儲存庫打造
- 透過 OAuth 或個人存取權杖登入後瀏覽 GitHub 儲存庫
- 將專案直接複製到 Android App 儲存空間
- 不需要系統 git 執行檔即可執行 Git 操作

安心同步
- 查看分支、乾淨或已修改狀態、已暫存檔案與未追蹤檔案
- 確認儲存庫狀態後安全拉取
- 在捨棄或提交變更前逐行檢視 diff
- 提交本機變更並推送回遠端儲存庫

本機 Git 工具箱
- 暫存與取消暫存個別檔案
- 建立、切換、合併與刪除分支
- 以 ours、theirs 或手動選擇解決衝突
- 檢視歷史記錄、建立與復原 stash、管理標籤

專為行動裝置設計
- 流暢的 Jetpack Compose 介面
- 深色與淺色模式
- 使用 App 儲存空間作為複製位置，確保 Android 相容性
- 免費下載，透過 Google Play 一次性 App 內購買解鎖完整功能
- 無廣告、無訂閱

Gitsync.md 專為開發者、寫作者，以及所有在 Android 上管理 GitHub 檔案的人打造。若要存取私人儲存庫，請使用 GitHub 登入或提供個人存取權杖。權杖僅儲存在你的裝置本機。
