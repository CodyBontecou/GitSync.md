# Git tools language resources

Added **575 authored translations** for 23 existing keys across all 25 supported non-English locales. The additions cover commit selection/guidance, local commit and push progress, unstaged/copied/local-only/remote labels, conflict resolution/staging, operation headings, normal/forced branch deletion and merge-strategy choices. All **36 strings and three plurals** in the Git tools resource file now have mappings. Other raw model/default/conditional copy and language resources outside this file remain open.

BranchDialog maps the three merge choices to FF_ONLY, NO_FF and FF respectively. The translations preserve those policies and the explicit unmerged-branch deletion warning. They do not change Git behavior, imply remote publication, or promise a new merge commit for an already up-to-date branch. The 23 keys have no format arguments. English resource text, Kotlin, core code and the original 468 English extraction fixtures are unchanged. Human linguistic and terminology review remains pending.
