SSH 経由のセルフホスト Git に対応しました。このアップデートでは、SSH のみを公開している Forgejo および Git サーバーで、リポジトリのクローン、プル、プッシュが正しく動作するよう修正しています。

• iPhone と iPad に SSH トランスポートが正しく組み込まれました
• Ed25519、ECDSA、RSA の秘密鍵に対応しました
• 未知の SSH ホストでは、フィンガープリントを確認する信頼ダイアログが表示されます
• SSH ホストキーが変更された場合は、確認するまで接続をブロックします
• リポジトリ設定でリモート URL と SSH 認証情報を更新しやすくなりました

実際の Forgejo サーバーでのテストにご協力いただき、ありがとうございました。
