Тепер доступна робота із самостійно розміщеними серверами Git через SSH. Це оновлення виправляє підтримку серверів Forgejo й Git, які використовують лише SSH, під час клонування, отримання та надсилання репозиторіїв.

• Транспорт SSH тепер правильно вбудовано в застосунки для iPhone та iPad
• Підтримуються приватні ключі Ed25519, ECDSA та RSA
• Для невідомих хостів SSH тепер відображається запит довіри з відбитком ключа
• Змінені ключі хоста SSH блокуються, доки ви їх не перевірите
• У налаштуваннях репозиторію стало простіше оновлювати віддалені URL-адреси та облікові дані SSH

Дякуємо за допомогу в тестуванні на справжніх серверах Forgejo.
