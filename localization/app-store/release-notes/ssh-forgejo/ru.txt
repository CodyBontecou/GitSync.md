Теперь доступна работа с самостоятельно размещёнными серверами Git по SSH. Это обновление исправляет поддержку серверов Forgejo и Git, использующих только SSH, при клонировании, получении и отправке репозиториев.

• Транспорт SSH теперь правильно встроен в приложения для iPhone и iPad
• Поддерживаются закрытые ключи Ed25519, ECDSA и RSA
• Для неизвестных хостов SSH теперь отображается запрос доверия с отпечатком ключа
• Изменённые ключи хоста SSH блокируются до вашей проверки
• В настройках репозитория стало проще обновлять удалённые URL-адреса и учётные данные SSH

Спасибо за помощь в тестировании на реальных серверах Forgejo.
