รองรับ Git ที่โฮสต์เองผ่าน SSH แล้ว การอัปเดตนี้แก้ไขการรองรับเซิร์ฟเวอร์ Forgejo และ Git ที่ใช้ SSH เท่านั้น สำหรับการโคลน ดึง และพุชคลัง

• รวมการรับส่งข้อมูล SSH สำหรับ iPhone และ iPad อย่างถูกต้องแล้ว
• รองรับคีย์ส่วนตัว Ed25519, ECDSA และ RSA
• โฮสต์ SSH ที่ไม่รู้จักจะแสดงข้อความขอความเชื่อถือพร้อมลายนิ้วมือของคีย์
• คีย์โฮสต์ SSH ที่มีการเปลี่ยนแปลงจะถูกบล็อกจนกว่าคุณจะตรวจสอบ
• การตั้งค่าคลังช่วยให้แก้ไข URL ระยะไกลและข้อมูลรับรอง SSH ได้ง่ายขึ้น

ขอบคุณที่ช่วยทดสอบกับเซิร์ฟเวอร์ Forgejo จริง
