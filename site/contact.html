Contact Cody Bontecou for GitSync.md support, product questions, and private data requests.

Contact the developer

GitSync.md is independently developed by Cody Bontecou. For support, product questions, or private data requests, email cody@isolated.tech. Include the platform you use, the app version, what you expected to happen, and the error message or steps that reproduce the problem.

Public bug reports

For non-private bugs and feature requests, use GitSync.md GitHub Issues. Check whether an existing issue describes the same problem before opening a new one. A small example with the steps you followed is more useful than uploading an entire repository.

Keep private information private

Never post passwords, GitHub tokens, SSH private keys, repository contents, installation identifiers, or other private data in a public issue. Remove sensitive details from screenshots and error logs before sharing them. For a privacy or data request, use email or the private in-app email flow described in the privacy policy.

Try the relevant guide first

The Obsidian Git troubleshooting guide covers common iPhone authentication and sync problems. The conflict recovery guide explains how to recover when two devices edit the same files. Keep a separate backup before making recovery changes to your vault.
