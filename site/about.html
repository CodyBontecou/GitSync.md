About GitSync.md and its developer

Learn about GitSync.md, the independently developed Git client for iPhone, iPad, and Android, and the person behind it.

Built by an independent developer

GitSync.md is built by Cody Bontecou. It is a Git client for people who want to work with their own repositories from a phone or tablet: notes in an Obsidian vault, drafts in a local folder, or files in a code project. The iPhone and iPad app supports reviewing changes, staging files, committing, pulling, and pushing, with Git operations running on the device.

Your files and your Git remote

GitSync.md connects to the Git provider you configure. The iPhone and iPad client supports HTTPS and SSH remotes, including self-hosted providers. You can clone a repository or publish reviewed local files to a new private repository in your personal GitHub account. GitSync.md is independently developed and is not an official Obsidian or GitHub product.

Platforms and pricing

The iPhone and iPad app costs $19.99 once on the US App Store, with unlimited repositories and no subscription. The Android app costs $9.99 once on Google Play, with all features included. Local prices may differ. The guides on this website describe iPhone and iPad workflows unless they explicitly say otherwise; availability on Android does not imply identical features.

Learn more or get in touch

Read the setup and troubleshooting guides, inspect the source repository, or use the contact page for help. The privacy policy explains how the app handles credentials, optional background features, and data requests.
