Is Obsidian Sync worth it?

Disclosure: this page is published by the developer of GitSync.md, a Git client for iPhone, iPad and Android. GitSync.md is independent of Obsidian. The calculator uses Obsidian’s, GitHub’s and Apple’s published prices and doesn’t favour one result.

Sync is the right call if you want end-to-end encryption without extra work, no setup beyond signing in, sync that runs on its own, and support from the Obsidian team.

Git is worth it if you want every change as a commit you can diff and restore, a remote you choose, and no subscription. You trade that for setup time, credentials on each device, and conflicts you resolve yourself. Keep in mind that a private GitHub repository is not end-to-end encrypted.

iCloud is enough for many people who use only a Mac, iPhone and iPad and don’t need version history inside Obsidian.

Free and one-time ways to sync

  • iCloud Drive (Apple devices only). Obsidian recommends it for macOS, iOS and iPadOS. It warns that “iCloud Drive on Windows may lead to file duplication or corruption”, and there is no iCloud Drive app for Android or Linux. The free tier is 5 GB, shared with backups and photos; iCloud+ starts at $0.99 a month for 50 GB in the US (Apple’s iCloud+ plans).
  • Git with a private GitHub repository. GitHub Free includes unlimited private repositories (GitHub pricing). On a computer, Git and the community Obsidian Git plugin are free. A phone needs a Git client that can reach the vault folder: GitSync.md is free to download, with a $9.99 one-time unlock on iPhone and iPad and $9.99 once on Android. Follow Sync Obsidian with GitHub on every device.
  • Syncthing and third-party plugins. Obsidian’s guide describes Syncthing as decentralized sync that works best with one device always on, and lists it as not officially supported on iOS. Other services and plugins exist; check each one’s own documentation.

Obsidian keeps an overview of all of these in Sync your notes across devices. Whichever you choose, use one sync method per vault.

How the numbers are calculated

  • All prices are US list prices in US dollars, checked November 19, 2026, before sales tax or VAT. App Store, Google Play and iCloud prices vary by region.
  • Sync costs are the plan price × 12 × the number of years, at the billing you choose. Plus with more than 10 GB uses the 100 GB price from Obsidian’s announcements. No discounts are applied.
  • Storage is compared with the size you enter. Version history also uses Sync storage, so the calculator warns you when your vault is within 20% of a limit.
  • The Git route counts a free private GitHub repository, free desktop Git, and one GitSync.md unlock for each mobile platform you tick ($9.99 for iPhone/iPad, $9.99 for Android). It doesn’t count Git LFS or other paid GitHub add-ons.
  • The iCloud route is $0 up to the 5 GB free tier, then the smallest iCloud+ plan that holds the vault. It ignores what else already uses your iCloud storage.
  • Sizes are treated as decimal units (1 GB = 1,000 MB). GitHub states its limits in MiB, which are about 5% larger.
  • Nothing you enter leaves your browser or is saved. The calculator makes no network requests.

Frequently asked questions

Is Obsidian Sync free?

No. Obsidian itself is free, but Obsidian Sync is a paid add-on. As checked November 19, 2026, Sync Standard costs $4 USD a month billed annually or $5 billed monthly, and Sync Plus costs $8 a month billed annually or $10 billed monthly. You can sync a vault for free with iCloud on Apple devices, or with Git on desktop computers.

Is 1 GB of Obsidian Sync storage enough?

For a text-only vault, usually yes: a Markdown note is a few kilobytes. Attachments and version history fill it faster, because Obsidian counts both toward the storage limit. Standard also skips any file over 5 MB, so a vault with large PDFs, images or recordings may need Sync Plus.

Can I sync Obsidian with GitHub for free?

On desktop computers, yes. GitHub Free includes unlimited private repositories, and Git and the community Obsidian Git plugin are free. On a phone you need a Git client that can reach the vault folder. GitSync.md is free to download and costs $9.99 once to unlock on iPhone and iPad, and $9.99 once on Android. GitHub blocks files over 100 MiB, so very large attachments need Git LFS or another home. To find which files are too big, use the GitHub file size checker.

Does a private GitHub repository encrypt my notes?

No. A private repository limits who can open it, and HTTPS or SSH protects the transfer, but the notes are not end-to-end encrypted: GitHub can read them. Obsidian Sync uses end-to-end encryption by default. If your notes need that, choose Sync or encrypt them yourself before they reach the repository.
