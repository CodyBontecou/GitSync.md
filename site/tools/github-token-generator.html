What this token allows

    One step left on GitHub: under Repository access choose Only select repositories and pick your vault repository. The link can’t do that for you.

    Last checked: November 22, 2026, against GitHub Docs: Managing your personal access tokens and the GitHub changelog on template URLs for fine-grained tokens. Parameters used here: name (40 characters or fewer), description (1024 or fewer), target_name, expires_in (1–366 or none; GitHub’s default is 30 days) and permission names with read or write. write includes read, metadata is read-only and workflows is write-only.

    Which preset?

    • Obsidian Git plugin: contents=write, statuses=write, metadata=read. The Obsidian Git docs list read access to metadata and read/write access to contents and commit status as the minimum for mobile.
    • Sync a repo in a Git app: contents=write (plus metadata=read, which GitHub grants anyway). Enough to fetch, pull and push over HTTPS.
    • Read-only clone or backup: contents=read. Pushes will be refused.
    • Publish a site with GitHub Actions: adds workflows=write. You only need it if you edit files in .github/workflows/; for ordinary note edits, the Obsidian Git preset is enough. See publishing Obsidian notes with Quartz from your iPhone.

    After you open the link

    1. Check the pre-filled name, description, owner and expiration on GitHub’s form.
    2. Under Repository access, choose Only select repositories and pick your vault repository.
    3. Check the permissions list matches what you chose here, then tap Generate token.
    4. Copy the token right away. GitHub shows it once.

    Where to paste it

    Keep the token safe

    • Never paste it into a note: the note gets committed and pushed.
    • Exclude plugin data from Git before you enter it. The .gitignore generator and the .gitignore guide show how.
    • If it is exposed, revoke it on GitHub and create a replacement.
    • GitHub removes tokens that go unused for a year, according to its docs.
    • If a token expires, generate a new one with this page and enter it again. See Obsidian Git not working on iPhone.

    Frequently asked questions

    Does this tool see my token?

    No. It only assembles a URL in your browser. The token is created on github.com after you open the link. The page makes no network requests and stores nothing.

    Why can’t it pick my repository?

    GitHub’s documented URL parameters cover the name, description, owner, expiration and permissions, not the repository selection. Choose Only select repositories on the form yourself.

    Which permissions does Obsidian Git need?

    Read access to metadata and read/write access to contents and commit statuses, per the plugin’s docs. That is the first preset.

    Can I use SSH instead?

    Yes, if your Git client supports SSH keys, which avoids tokens. See SSH Git on iPhone. Note the Obsidian Git plugin’s mobile limits in its setup guide.
