Start with your files →Watch: Obsidian to GitHub from iPhone →

  1. 01

    Pick your folder.

    Choose Add Repository → Publish a Folder, select a supported local folder in Files, and sign in with GitHub.

  2. 02

    Choose what goes in.

    Review and select your files, set your author details, and save the first commit on-device. Nothing is uploaded in this step.

  3. 03

    Make it a private GitHub repo.

    A separate publish action creates a private repository in your personal GitHub account and pushes your saved commit. Keep the app open for the first upload.

First publication supports local app folders under On My iPhone or On My iPad and regular files up to 10 MiB each. Cloud-provider folders and Git LFS publication are outside this flow.

Good questions

Before you commit.

A few things to know. For everything else, get in touch ↗

How does pricing work?

On iPhone and iPad, GitSync.md is $9.99 on the US App Store, paid once. Unlimited repositories, the editor, all manual Git tools, and optional Background Sync are included. On Android, GitSync.md is $9.99 on Google Play, paid once, with all features included. Neither version has a subscription. Local store prices may vary.

Can I create a repository on my device?

Yes. On iPhone and iPad, choose Add Repository → Publish a Folder and sign in with GitHub. Select an existing local folder, review the files, and prepare the initial commit in place. Uploading is a separate action that creates a new private repository in your personal GitHub account. This flow supports local app folders under On My iPhone or On My iPad, with regular files up to 10 MiB each; cloud-provider folders, empty repositories, and Git LFS publication are outside this flow. See how it works →

Does it work with my Obsidian vault?

Yes. Clone your vault into a Files location Obsidian can access, then use GitSync.md to pull and push. Shortcuts and syncmd:// links can trigger repository actions. Follow the setup guide →

Can I use private or self-hosted repos?

Yes. Use GitHub OAuth or a Personal Access Token for GitHub, or connect another Git remote over HTTPS or SSH with its own credentials. GitLab, Bitbucket, Gitea, and Forgejo are supported.

What happens when there's a conflict?

Review conflicts in the Conflict Center. Choose ours or theirs, or edit a merged result in the three-way view. Continue or abort a merge or rebase explicitly. It's a real Git working copy, so you can also finish on desktop.

How automatic is Background Sync?

You choose automatic pulls, automatic commit and push, or both. Publishing starts off. Sync attempts happen when the app opens and when iOS allows background processing; they aren't guaranteed or real time. Concurrent edits and unsafe Git states stop for your attention.

Where do my files and data go?

Files live on your device, and Git operations talk directly to your remote. Credentials stay in Keychain. Separately opted-in Push Sync uses a relay for repository names, GitHub installation/account identifiers, and APNs registration data, but never file contents, local paths, or Git credentials. The app also collects coarse onboarding analytics. Read the privacy policy →

Which platforms can I install it on?

GitSync.md is available for iPhone and iPad on the App Store, and for Android on Google Play. The iPhone and iPad app requires iOS 17 or iPadOS 17 or later; its Control Center pull button requires iOS 18 or later. The Files, Apple Shortcuts, and on-device folder publication workflows shown here describe the iPhone and iPad app.
