Description of the App

GitSync.md is a paid, open-source iOS application that provides Git version control functionality on iPhone and iPad. The base App is available as a one-time App Store purchase. It uses libgit2 for local Git operations and connects directly to the Git provider you configure. Manual Git operations, Shortcuts, callbacks, Background Sync, and local features are all included with the one-time purchase.

Background Sync is included with the App purchase and provides best-effort repository reconciliation while the App is closed. After one explicit installation-level opt-in, it applies to all current and future cloned or managed repositories unless you exclude one. Reconciliation runs entirely on your device using the App's own Git engine and is attempted when the app is activated in the foreground and when iOS grants discretionary background processing time. Apple and iOS do not guarantee background delivery, timing, frequency, or execution; Background Sync is not guaranteed or truly real-time syncing. An optional Push Sync setting — off by default — lets you install the GitSync.md GitHub App once per personal account or organization, with access to all or selected repositories, instead of configuring repository webhooks. It delivers a best-effort alert and asks iOS for bounded reconciliation of the matching included branch when automatic pull is enabled. Separately enabled publishing keeps the same safety rules; iOS may suppress the attempt, and tapping remains a pull-only fallback. The first-party relay stores repository names, verified GitHub installation/account identifiers, and APNs registration data and transiently routes branch and commit hints, but never receives local repository contents, local paths, or Git credentials.

Background Sync Safety Terms

While Background Sync is enabled, you can independently turn automatic pull and automatic publishing on or off. Pulls are limited to clean fast-forwards on each repository's configured checked-out branch. Publishing requires separate, default-off consent and may stage all non-ignored local edits, create a commit with the configured author and default message, and push directly from your device to the configured Git provider. With pull off, push-only mode still fetches remote metadata for safety but does not update the worktree. The App never force-pushes, rebases, merges, switches branches, resolves conflicts, or recreates missing branches. Remote-ahead local edits, divergence, a missing or wrong branch, authentication/trust requirements, unavailable files, and failures require manual attention. A failed push may leave a safe local commit for later retry. Per-repository network/power policies and exclusions remain under your control.

Because Background Sync runs entirely on your device, its availability depends on iOS granting background time rather than on a service we operate. Force-quit behavior, Low Power Mode, network/power policy, and operating-system scheduling can delay or prevent background processing. Background Sync is not guaranteed or real time. Global disable prevents new automatic work and requests cancellation of work already in flight. A Git update or publication that completed before cancellation cannot be recalled.
