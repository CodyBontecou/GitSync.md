Obsidian Sync alternatives: what works on iPhone, Android and desktop.

Pick a replacement for Obsidian Sync by the devices you own first, then by how much setup you will put up with. Most of these methods work fine on desktop. The differences show up on iPhone.

This page compares ways to sync an Obsidian vault. If you are looking for a different note-taking app instead of Obsidian, this isn’t that list.

Short answer
  • Only Apple devices (Mac, iPhone, iPad): use iCloud Drive. It is free within your iCloud storage and one of the two methods Obsidian recommends for iPhone.
  • Windows or Android plus an iPhone, and you want version history: use Git with GitHub or your own server. Run the Obsidian Git plugin on the computer and a native Git client on the phone.
  • Peer-to-peer on your own network, no cloud: Syncthing, if you accept that iPhone support comes only from third-party apps with background limits.
  • You already run a server: Self-hosted LiveSync syncs changes quickly through CouchDB or object storage.
  • You already pay for cloud storage (S3, Dropbox, OneDrive, WebDAV): Remotely Save.
  • You want zero setup: keep Obsidian Sync. It is the easiest and the only officially supported option on every platform.

Disclosure: GitSync.md’s developer publishes this comparison, and GitSync.md is one of the Git clients mentioned. Each claim about another product links to its own documentation, reviewed November 19, 2026. This is a comparison of documented behavior, not a speed or reliability test. GitSync.md is independent of Obsidian and of every project listed here.

Whatever you pick, Obsidian’s File recovery core plugin saves local snapshots of your notes on each device. By default it keeps them for 7 days. It is a safety net, not a backup. To make Git your backup, see how to back up and restore notes with Git.

iCloud Drive: free and simple, for Apple devices only

How it works. The vault is an ordinary folder in iCloud Drive, and Apple’s file sync moves it between your Mac, iPhone and iPad. On iPhone you create the vault with Store in iCloud turned on.

The iPhone caveat. Obsidian’s sync guide says the vault must be inside the Obsidian folder in iCloud Drive, at iCloud Drive/Obsidian/Your Vault, and warns that a vault elsewhere may have syncing issues. There is no Android route. On Windows, Obsidian warns that iCloud Drive “may lead to file duplication or corruption”, so there is no Windows-to-iPhone path that works well.

Who it suits. People whose devices are all Apple devices and who don’t need note history.

What usually goes wrong. The Mac offloads files to save space, so Obsidian can’t see notes that are only in the cloud. Obsidian’s guide says to keep the vault folder downloaded (Keep Downloaded on macOS 15 or later). iCloud doesn’t give you a per-note history either. For a closer look, read iCloud vs Git for Obsidian.

Git: history and explicit conflicts, on any device

How it works. The vault is a Git repository with a remote such as a private GitHub repository or your own server. Every device has a full local copy. You commit a snapshot, push it, and pull on the next device. On a computer, the Obsidian Git plugin can do that on a timer.

The iPhone caveat. The same plugin runs on mobile through a JavaScript Git implementation. Its README calls mobile support “very unstable” and lists the limits: no SSH authentication, limited repository size because of memory, and possible crashes on clone or pull. So on a phone, a native Git client does the Git work while Obsidian edits the same local folder. GitSync.md is one such client for iPhone, iPad and Android. It supports HTTPS and SSH remotes, including self-hosted ones, and costs $9.99 once on the US App Store and on Google Play, with no subscription (pricing). If you prefer to run Git from inside Obsidian, the free GitSync.md Connect plugin passes your GitHub sign-in from the app to the Obsidian Git plugin. (The plugin README also mentions an app called “GitSync”. That is a different project.)

Who it suits. Mixed devices (Windows or Android plus iPhone), anyone who wants to see and undo every change, and anyone who would rather not pay a subscription.

What usually goes wrong. Forgetting to pull before writing on a second device, which leaves Git with a conflict to resolve. Sync is a step you or a schedule takes, not a live connection. On iPhone, GitSync.md’s Background Sync is best-effort, because iOS decides when apps run in the background; read what automatic Git sync can do on iPhone. To set it up, follow how to sync Obsidian with GitHub on every device, or compare it head-to-head in Obsidian Sync vs Git.

Syncthing: peer-to-peer and free, with a weak iPhone story

How it works. Syncthing copies the vault folder directly between your devices, with no server keeping a copy. It is free and open source. Because there is no central copy, two devices have to be online at the same time to exchange changes, so many people keep one always-on computer in the mix.

The iPhone caveat. There is no official iOS app. The Syncthing FAQ says the team has no plans to support iOS and that iOS background restrictions “make it very hard to run Syncthing reliably”. It points to two third-party options: the open-source Synctrain and the commercial Möbius Sync. On Android, the official app was archived in December 2024; the community contributions page lists maintained forks such as Syncthing-Fork.

Who it suits. Desktop and Android users who want their notes to stay on their own devices and don’t mind running Syncthing everywhere.

What usually goes wrong. Two devices edit the same note while apart, and Syncthing keeps both and renames the older one to a .sync-conflict file that you have to merge by hand. File versioning is off by default, so a deleted note is gone everywhere unless you turned it on.

Self-hosted LiveSync: fast sync if you run a server

How it works. Self-hosted LiveSync is a community plugin that syncs through a CouchDB database or S3-compatible object storage (such as Cloudflare R2 or MinIO), or peer-to-peer over WebRTC. It syncs in close to real time while Obsidian is open. It supports end-to-end encryption. The plugin is free; the server is yours to run or rent, and its README asks you to “set up and maintain your own server, and keep it secure”.

The iPhone caveat. It runs inside Obsidian on iPhone and Android, but a self-hosted CouchDB must be reachable over HTTPS from the phone, and the README notes that peer-to-peer mode is limited by OS background tasks. Obsidian lists LiveSync among the plugins that “aren’t officially supported” on iOS.

Who it suits. People who already run a home server or a small cloud instance and want sync that feels close to Obsidian Sync.

What usually goes wrong. Running it alongside another sync method. The README says not to enable it “alongside another synchronisation solution (including iCloud and Obsidian Sync)”. Back up the vault before you set it up.

Remotely Save: sync through cloud storage you already have

How it works. Remotely Save is a community plugin that uploads and downloads the vault to a storage service. The free version supports Amazon S3 and S3-compatible storage, Dropbox, OneDrive for personal (app folder), WebDAV (for example Nextcloud or Synology) and Webdis. Google Drive, Box, pCloud, Yandex Disk, Koofr, Azure Blob Storage and full OneDrive access are PRO features. Its website said on November 19, 2026 that PRO is free during a beta that ends January 1, 2027, with a price to be set later. Your storage provider may charge separately. Files can be encrypted with a password before upload.

The iPhone caveat. It works in Obsidian on iPhone and Android, but the README says auto sync “only works when Obsidian is being opened” and that background sync is “technically impossible”. It also warns about slow syncing of files of 50 MB or more on mobile.

Who it suits. People who already pay for S3, Dropbox, OneDrive or a WebDAV server and want a plugin-only setup.

What usually goes wrong. Conflicts. The free version detects them but only lets you keep the newer or the larger file, so the other edit is lost; PRO’s smart conflict merges small Markdown files. Errors in auto sync “fail silently”, per the README, so check it now and then.

Obsidian Sync: the easiest option, and the official one

How it works. Obsidian’s own service syncs vaults on Mac, Windows, Linux, iOS and Android. Obsidian’s pricing page says your data is “secured with AES-256 end-to-end encryption, preventing us from reading it”, and note history is built in. Its security documentation explains the encryption options. It is the only method on this page that Obsidian officially supports on every platform, and setup is a sign-in.

The iPhone caveat. None to speak of. It is one of the two methods Obsidian recommends for iPhone and iPad.

Who it suits. Anyone who wants sync to just work and is happy to pay for it. As reviewed on November 19, 2026, obsidian.md/sync lists a Standard plan (1 vault, 1 GB, 1 month of history) and a Plus plan (10 vaults, 10 GB, 12 months of history); check the pricing page for current prices and discounts.

What usually goes wrong. Automatic merging. By default Sync merges conflicting Markdown edits into one note, which the troubleshooting guide says can “create duplicate text or formatting problems”. Since Obsidian 1.9.7 you can choose Create conflict file instead, on each device.

Switching from Obsidian Sync without losing notes

  1. Let Obsidian Sync finish on every device, then pause or disconnect it everywhere.
  2. Pick one device as the source of truth: the one with the newest, most complete copy.
  3. Make a backup copy of that vault folder somewhere no sync tool touches. Open a few notes and attachments from the copy to check it.
  4. Set up the new method on the source device first. For Git, decide what to leave out of the repository with an Obsidian .gitignore before the first push.
  5. Add the other devices one at a time. Create a test note on each and confirm it arrives on another device, then edit it there and check it comes back.
  6. Never run two sync methods on the same vault folder. Obsidian’s guide warns this can cause “data conflicts or corruption”.

FAQ

Is there a free Obsidian Sync alternative for iPhone?

Yes. If all your devices are Apple devices, iCloud is free up to your iCloud storage and is one of the two options Obsidian recommends for iPhone and iPad. For other device mixes, Self-hosted LiveSync and the free tier of Remotely Save are free plugins, but you pay for or run the storage they use. Git is free on the desktop and the Obsidian Git plugin is free on mobile, though its README calls mobile support very unstable. A native Git client such as GitSync.md is a one-time $9.99 purchase.

Can I use Obsidian Sync and Git together?

It is possible, but Obsidian advises against syncing the same vault with more than one service. Two systems rewriting the same files can turn one edit into a merge conflict or a duplicate note. If you want Git as a backup of an Obsidian Sync vault, let one computer commit and push it to a repository, and don’t also open that repository as a synced vault on your other devices.

Which alternative keeps version history?

Git keeps every commit you push, with diffs, for as long as the repository exists. Obsidian Sync keeps note history for 1 month on Standard or 12 months on Plus. Syncthing can keep old versions, but file versioning is off by default. iCloud, LiveSync and Remotely Save do not document a version history for your notes. Obsidian’s File recovery core plugin keeps local snapshots on each device whichever method you choose.

Does any alternative sync in the background on iPhone?

Not reliably. iOS decides when apps get background time. Remotely Save’s README says auto sync only works while Obsidian is open, Syncthing’s FAQ explains that iOS background limits make it hard to run reliably, and GitSync.md’s Background Sync is best-effort. Open the app and sync before you switch devices.
