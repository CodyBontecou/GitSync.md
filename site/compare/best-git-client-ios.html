Short answer
  • Markdown or Obsidian vault: GitSync.md, with push included in its one-time price.
  • Other work on a local repository: Working Copy has the longest feature list, but pushing needs its Pro unlock.
  • Pull requests and issues only: GitHub Mobile, which does not describe a local working copy.
  • A terminal: a-Shell or iSH, both free to download.

Disclosure: this page is published by GitSync.md’s developer. Competitor facts come from each app’s official site, App Store listing or documentation, checked November 20, 2026. It is not a hands-on performance test. Prices and features change; where a source did not state a fact, the table says “not documented”.

“Git client” means different things on iOS because apps are sandboxed. A local working copy app stores a real repository on the device, so you can commit offline and, if it exposes the folder through the Files app’s document provider system, let other apps such as Obsidian open the same files. A remote-only app talks to GitHub’s servers and keeps no repository on the phone. A terminal app gives you command-line Git inside its own sandbox. Which one you want depends on the job.

App by app

GitSync.md

Good at: Markdown and Obsidian vaults. It keeps a real local Git repository and includes the editor, manual Git tools, unlimited repositories, optional Background Sync and a free Connect companion (its credential handoff is for GitHub HTTPS remotes only). Limits: it is a Git client and editor, not a terminal or build environment, and background work is best effort because iOS schedules it. Price: free download; cloning needs a $9.99 one-time unlock, no subscription (US App Store listing); Android is $9.99 once on Google Play. Pick it if your files are notes. View it on the App Store →

Working Copy

Good at: the broadest feature list of the local-repository apps. Its App Store listing shows merge and rebase tools, Shortcuts actions, Files integration, SSH keys for authentication and signing, and Markdown and HTML previews; its site lists LFS. Limits: the listing says pushing and more than five repositories need Pro, and the manual documents Auto-Sync as Pro. Price: free to download with a 10-day Pro trial; the US listing shows a $29.99 Pro unlock and says upgrades add newer features for a year. Pick it if you need its signing or search and accept the unlock. For a head-to-head, read GitSync.md vs Working Copy.

Phogit

Good at: a newer local-repository client for iPhone and iPad with HTTPS and SSH cloning, a Files location, LFS support, a merge tool and a commit graph, per its App Store listing. Limits: pushing, SSH key management, rebase and background checks are Pro; it requires iOS/iPadOS 27 or later, and its listing shows version 1.0.0, released November 6, 2026 (site). Price: free to download; Phogit Pro 2026–2027, $19.99 once; Pro features added after the 2027 edition need the newer edition. No Android app is listed. Pick it if you run the latest iOS and want to try a newer client.

GitHub Mobile

Good at: what its docs describe: notifications, issues, pull-request review and editing files within a pull request, on iOS and Android. Limits: the documentation does not describe cloning, so there is no local working copy to open from other apps. Price: free, with optional in-app purchases for GitHub and Copilot plans on the App Store listing. Pick it for review and triage, alongside another client.

a-Shell and iSH

Good at: scripting and command-line Git. a-Shell’s App Store listing says you can work with repositories using lg2 and lists ssh, scp and curl; its project page says it is open source and uses iOS file sharing. iSH’s project page describes a Linux shell using a usermode x86 emulator and says it will always be free. Limits: neither source documents a full Git workflow, so installation, credentials and folder handling are yours to work out; the iSH App Store version listed shows its latest version as May 2023, so check that it still suits your iOS version. Price: both free. Pick them if you are comfortable in a shell.

Other apps and older apps

Gitox is an iPhone client whose site lists clone, edit, commit and push, SSH keys, OAuth and tokens, a free tier and a $9.99 one-time Pro. Its App Store listing is iPhone only (no iPad), needs iOS 16 or later, and shows version 1.2.0 from May 2, 2026; Files access and LFS are not mentioned, so it is not in the table. Clone by Dan Leehr L.L.C. is free with a $9.99 “Publish and Push” purchase, but its App Store listing shows version 1.4.0 from August 3, 2020 as the latest, so we treat it as an older app.

Is there a free Git client for iOS that can push?

Not among the local-repository clients with a documented free push that we checked. Working Copy and Phogit are free to download but list pushing as a Pro feature. GitSync.md is a free download, but cloning needs a $9.99 one-time unlock that includes push. Clone’s push sits behind a one-time purchase.

The free routes are the terminal apps and Gitox, whose site lists a “$0 forever” Free tier with “Full Git operations” and whose listing marks only the AI Agent as Pro. Gitox’s site and listing describe push in its free tier; we have not tested it. a-Shell and iSH cost nothing and can run Git commands, but you set up the tooling and credentials, and the sources above do not document the steps. GitHub Mobile is free but cannot be your working copy.

You need a client that stores the vault where Obsidian can open it. Start with the iPhone and iPad setup guide. On Android? See the Android comparison or Obsidian Git on Android; if Git is not settled, compare Obsidian Sync alternatives. For large attachments, read Git LFS on iPhone and iPad.

Common questions

Can an iPad run real Git?

Yes, for the Git part. Native clients such as GitSync.md, Working Copy and Phogit keep a local repository on the device and can commit offline. iPadOS does not give them a desktop build environment, so they edit and version files rather than compile projects. See Git on iPad.

Do I need a Mac to use Git on iPhone?

No. Cloning, committing and pushing run on the device in the native clients above. You need connectivity to reach the remote, and credentials the remote accepts.

Should I use SSH keys or a token?

Either works where a client supports it. A token over HTTPS is the simplest start for GitHub; SSH suits self-hosted servers. Support differs by app, so check the table first. For a self-hosted server, follow the SSH setup guide.

Does GitHub Mobile clone repositories?

GitHub’s documentation lists notifications, issues, pull requests, repository and code search, and editing files in pull requests. It does not describe cloning a repository to the device, so treat it as a companion to a Git client rather than a replacement.
