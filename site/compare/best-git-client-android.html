Short answer
  • Notes and Obsidian vaults: GitSync.md, which clones into a normal device folder, or GitJournal if you want a notes app with Git built in.
  • Hands-on Git on files, free and open source: Gitling (updated November 20, 2026) or PuppyGit (updated November 17, 2026). MGit’s last release was January 2023.
  • A terminal: Termux. Pull requests and issues only: GitHub Mobile, which does not describe cloning.

Disclosure: this page is published by GitSync.md’s developer. Facts about other apps come from the sources linked in each row and section, checked November 25, 2026. It is not a hands-on test. Where a source did not state a fact, the table says “not stated” or “see listing”.

On Android, “Git client” covers four different jobs: running Git on files in a folder, a notes app with Git sync built in, browsing GitHub, and a shell. Pick the job first, then the app.

App by app

GitSync.md

Good at: keeping a Git working copy in a normal device folder, such as Documents/Obsidian, so Obsidian can open the same files. It supports HTTPS and SSH, with an SSH key made on the phone or imported, and it finds existing clones in a device folder. Limits: it is a paid app, and Background Sync is optional and runs only when Android schedules it; it is not real-time. Price: $9.99 once on Google Play after a free vault check, no subscription. Pick it if your files are notes or a vault. Get GitSync.md on Google Play → Details: Obsidian Git on Android.

MGit

Good at: the basics. Its F-Droid listing describes cloning, pushing and pulling, and committing and staging offline. Limits: the newest release on its releases page is v1.7.0 from January 2023, and we found no newer one. Price: free, GPL-3.0. Pick it if you already use it and it works for you; for a maintained fork, see Gitling.

Gitling

Good at: hands-on Git. Its F-Droid page calls it a fork of MGit with a Jetpack Compose interface, GitHub sign-in, HTTP, HTTPS and SSH, personal access tokens, key generation, branches, tags, rebase, cherry-pick, diffs and importing repositories from device storage. Version 1.0.66 is dated November 20, 2026. Limits: it has no built-in text editor; you need a separate editor app that supports Android’s File Provider. Price: free, GPL-3.0 or later. Pick it if you want a free, current client and already have an editor.

PuppyGit

Good at: a lot in one app. Its README lists fetch, merge, pull, push, commit history, rebase, cherry-pick, stashes, submodules, a file explorer, a simple UTF-8 editor and Markdown preview. Limits: the README says it needs a private key and passphrase for SSH and does not generate SSH keys; make the key elsewhere. Its latest GitHub release, 1.1.5.10v136, is dated November 17, 2026 (releases page). Price: GPL-3.0; see listing for how each build is distributed (the README links IzzyOnDroid). Pick it if you want an editor and Git together and are fine with a dense interface.

GitJournal

Good at: being a notes app first. gitjournal.io describes mobile-first Markdown notes integrated with Git, using standard SSH with GitHub, GitLab, Gitea or self-hosted servers; its GitHub repository lists AGPL-3.0. Limits: it is a notes app, not a general Git client, and the newest GitHub release we found is v1.80.0 from September 15, 2021, so check its Google Play listing for the current build date. Price: per its pricing page, Basic is free on Android and Pro is pay-what-you-want with a minimum; see listing for exact prices. Pick it if you want a notes app that syncs through Git rather than a separate Git client.

Termux + git

Good at: flexibility. The F-Droid page describes a terminal emulator with packages, including Git and the OpenSSH-related tools. Limits: you write and maintain your own scripts, and the listing’s newest entry is a beta (0.119.0-beta.3, May 29, 2025) with 0.118.3 the newest stable, same date. Price: free, GPL-3.0. Pick it if you are comfortable in a shell. For a vault setup with Termux, see Obsidian Git on Android.

GitHub Mobile

Good at: what the GitHub Mobile docs describe: notifications, issues, pull-request review and editing files in pull requests. Limits: the docs do not describe cloning or committing to a local working copy. Price: free; see listing for in-app purchases. Pick it for review and triage next to a real Git client. Need a token for HTTPS? Try the GitHub token generator.

Obsidian Git plugin on mobile

The plugin runs inside Obsidian. Its Obsidian Git README marks mobile as experimental and lists limits, including no SSH authentication; our Obsidian Git on Android guide covers them so this page doesn’t repeat them.

Why some Android Git apps stop working on new Android versions

A Git working copy is a normal folder with many small files and a hidden .git directory. For Obsidian to open those files, the Git app has to write them to a folder both apps can reach, such as Documents/Obsidian/MyVault. The Android storage documentation explains the model: apps that target Android 10 and higher get scoped access by default, limited to their own directory and media they created; Android 11 adds the MANAGE_EXTERNAL_STORAGE permission for broader write access, and the system file picker (Storage Access Framework) is the route for documents.

A client written before this model may keep its repositories in its own app directory, or lose write access to a shared folder. That can make a vault in Documents unreachable from the Git app or from Obsidian. This is the general mechanism, not a finding about any listed app: we did not test any of them, and we name none as broken. Check the Last release column, and try a free tool or a test folder before moving a real vault.

GitSync.md asks for all-files access so it can manage Git folders outside its own storage, and rejects cloud folders such as Google Drive that can’t hold a repository. See where the vault has to live.

How to choose

  • You want to edit code with a terminal → Termux.
  • You keep notes or an Obsidian vault in a device folder → GitSync.md, or GitJournal if you want the notes app built in.
  • You want free, open-source Git on files and a maintained app → Gitling or PuppyGit.
  • You only review pull requests and issues → GitHub Mobile.
  • You are on iPhone or iPad → see Best Git clients for iPhone and iPad.

Common questions

Does the GitHub app let you commit?

GitHub’s documentation for GitHub Mobile lists notifications, issues, pull requests, repository and code search, and editing files in pull requests. It does not describe cloning a repository or committing to a local working copy, so use it next to a Git client rather than instead of one.

Is MGit still maintained?

MGit’s newest release on its GitHub releases page and F-Droid listing is v1.7.0 from January 2023. We did not find a newer release as of November 25, 2026. Gitling, a fork of MGit on F-Droid, had a release on November 20, 2026.

Can I use SSH keys on Android?

Yes, in several clients. GitSync.md can make a key on the phone or import one, Gitling lists SSH keys with passphrases and key generation, and PuppyGit accepts a private key and passphrase but does not generate keys. The Obsidian Git plugin’s README lists no SSH authentication on mobile.

Do I need Termux?

No. Termux gives you a shell with Git, but a native Git client can clone, commit and push without a terminal. Termux is for people who want to script their own workflow.

Is there a free Git client for Android?

Yes. MGit, Gitling, PuppyGit and Termux are open-source apps listed on F-Droid or IzzyOnDroid, and GitJournal’s Basic tier is free on Android. GitSync.md is a paid app: $9.99 once on Google Play, after a free vault check.
