Short answer
  • GitSync is made by ViscousPot (ViscousPotential Ltd on the App Store). It is open source under GPL-3.0, runs on Android and iOS, and the App Store listing is free with in-app purchases. Pick it if you want open source, F-Droid, a free start or its Android triggers.
  • GitSync.md is made by Cody Bontecou. It is a native libgit2 Git client for iPhone, iPad and Android, $9.99 once on the US stores with no subscription. Pick it if you want a vault cloned into On My iPhone → Obsidian, Keychain credential storage, Shortcuts actions and the Connect companion for Obsidian Git.

For Obsidian on iPhone and iPad

GitSync.md: set the clone location to On My iPhone → Obsidian, clone the vault repository, then open that folder in Obsidian with Open folder as vault. Leave Store in iCloud off for this route. For Git commands inside Obsidian, GitSync.md Connect can configure the Obsidian Git plugin from your GitHub sign-in. Full steps: Obsidian Git on iPhone and iPad.

GitSync: the Obsidian Git docs point to the developer’s own setup tutorial. Follow that rather than a summary from us.

Whichever you use, iOS limits background work; see automatic Obsidian Git sync on iPhone.

For Android

Both apps run on Android. GitSync.md clones into a normal device folder such as Documents/Obsidian after you allow storage access, and Android decides when background checks run. Details: Obsidian Git on Android. GitSync’s README lists app-open and app-close triggers and a quick tile on Android, plus a schedule; for its folder access and background behavior, read its README and listing.

When the open-source GitSync is the better pick

  • You need GPL-3.0 software or F-Droid. GitSync is GPL-3.0 and listed on F-Droid and IzzyOnDroid.
  • You want no upfront cost. Its App Store listing is free, with in-app purchases.
  • You want its Android triggers and tiles. Sync on app open or close, a quick tile and a custom intent are in its README.
  • You want GitHub or GitLab issues and pull requests in the app. The README lists OAuth sign-in with issue and pull request features.

Switching between them

  1. Commit and push everything in the current app. Keep a separate copy of any unsynced notes.
  2. Clone the repository fresh in the other app, into a new folder.
  3. Do not point both apps at the same folder, and pause automation in the old app first.
  4. Check the new clone before removing the old one. Do not delete a vault as a migration step.

If a pull stops on a conflict, see resolving Obsidian Git merge conflicts on iPhone.

Common questions

Are GitSync and GitSync.md the same app?

No. They are separate apps from separate developers with no affiliation. GitSync is ViscousPot’s open-source app; GitSync.md is by Cody Bontecou.

Is GitSync.md open source?

The About page links its source repository. This page does not state a license for it; check the repository.

Which one does the Obsidian Git plugin documentation mention?

The open-source GitSync, as an app that is not associated with the plugin. The same docs also mention Working Copy. See GitSync.md vs Working Copy.

Can I use both?

Yes, on different clones. Both are Git working copies, so do not point both at one folder. See Switching.
