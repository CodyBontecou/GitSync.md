How to use Obsidian Git on iOS (iPhone and iPad).

On iOS the Obsidian Git plugin can’t run a native Git program, so you either rely on its built-in mobile implementation or let a native iOS Git app own the working copy that Obsidian opens. This guide compares the options, then clones a vault with GitSync.md, opens it in Obsidian, and verifies pull and push.

Obsidian Git plugin alone

The plugin’s documentation says the Git implementation on mobile is “very unstable”, that it uses isomorphic-git because native Git can’t be used on Android or iOS, that SSH authentication, the rebase merge strategy and submodules aren’t supported, and that repository size is limited by memory. It also says Obsidian may crash on clone or pull, or run indefinitely, depending on your device and free RAM. The full list is in Obsidian Git on mobile. It can still be enough for a small vault over HTTPS.

GitSync.md + Obsidian

This guide. GitSync.md is a native client built on libgit2 that keeps a real .git folder in a Files location Obsidian can open. It signs in with GitHub or takes an HTTPS token or SSH key, offers syncmd:// automation, requires iOS 17 or iPadOS 17, and costs $9.99 once on the US App Store. You can use it alone, or hand its GitHub sign-in to the plugin with Connect.

Working Copy + Obsidian

Working Copy is another native iOS Git client. It can link an external folder such as an Obsidian vault and does its own Git operations. Its pricing, as the official App Store listing and site show it, is a free download with a Pro unlock. For folder setup, authentication, automation and price side by side, read GitSync.md vs Working Copy.

Terminal apps: a-Shell and iSH

Running Git yourself is possible and manual. a-Shell’s App Store listing says you can work with repositories using lg2, and its project page says it is compatible with Apple Shortcuts and uses iOS file sharing. iSH’s project page describes a Linux shell on iOS. Installing Git, handling credentials and pointing at the vault folder are your job; see the best Git client for iOS for how these apps compare.

In-Obsidian GitHub-API sync plugins

obsidian-easy-git-sync describes itself as running entirely inside Obsidian, phones included, with no git or other app required. Per its README, you paste an access token, choose a repository on GitHub, GitLab, Bitbucket, Codeberg or your own HTTPS server, and each sync creates a commit; phones can’t use SSH. It syncs through your Git host rather than being described as a local Git working copy. See Obsidian sync alternatives for other approaches.

Which to pick: if you want the plugin’s commands inside Obsidian, configure Obsidian Git with Connect or a token. If you want reliable real Git, SSH or a self-hosted remote, let GitSync.md own the repository.

Why Obsidian Git needs help on iOS

On desktop, Obsidian Git can use installed Git tools. On iPhone and iPad it can’t, because, as the plugin’s documentation says, native Git can’t be used on iOS. It runs a JavaScript implementation with the limits above. Obsidian Git: commands, settings and common errors has the full list.

The second issue is where the vault lives. iOS apps are sandboxed, and another app can open your files only through locations the system exposes in Files, as Apple’s file provider documentation describes. So the repository has to sit in a folder both Obsidian and your Git app can reach, usually On My iPhone → Obsidian. GitSync.md uses libgit2 to clone, pull, commit and push a real repository in that folder: a normal .git directory, not a proprietary database or an API-only mirror.

Before you start

You need three things:

  • GitSync.md from the App Store.
  • Obsidian on the same iPhone or iPad.
  • A Git remote containing your vault. GitHub is the easiest path, but GitSync.md also supports manually entered remotes such as GitLab, Gitea, Bitbucket, or a self-hosted server over HTTPS token/password or SSH private key.

GitSync.md requires iOS 17 or iPadOS 17 or later and costs $9.99 once on the US App Store. Regional prices vary. Obsidian Git and GitSync.md Connect are separate community plugins; Connect requires GitSync.md 2.8.0 or later. Version 2.8.1 also supports connecting vaults published from a local folder.

Start with your existing vault

  • Already in a Git remote: follow the clone instructions below. The repository root should be your vault root.
  • Only on this iPhone or iPad: follow Publish a Folder to review your files, prepare an initial commit, and upload it to your personal GitHub account. Then return here to choose your daily Git workflow.
  • On another device, but not in Git: commit and push the vault there first, then clone it on your phone.

Keep an independent backup before changing sync methods. Choose one automation path initially so two apps do not attempt Git operations at the same time.

Avoid nested vault confusion

If the Git repository contains another folder named after the vault, Obsidian may open the wrong level. Clone a repo whose root is the vault, or be deliberate about which folder you open as the vault.

1. Clone the vault into an iOS Files location Obsidian can open

For a general code or document repository, follow cloning a GitHub repository on iPhone. The steps below focus on an Obsidian vault.

Choose the save location

Open GitSync.md and set the default save location to a Files location that Obsidian can access. For an Obsidian-first setup, the most direct destination is:

On My iPhone → Obsidian
On My iPad   → Obsidian

That puts the cloned Git repository directly in Obsidian's local file area. When the clone finishes, the folder is ready to open as a vault.

Add the remote repository

For GitHub, sign in with GitHub or paste a Personal Access Token, then pick the vault repo from your account. For a self-hosted remote, use manual repository entry and paste the clone URL:

https://git.example.com/team/notes.git
git@git.example.com:team/notes.git
ssh://git@git.example.com:2222/team/notes.git

Choose the matching authentication method: GitHub account, HTTPS token/password, SSH private key, or no authentication for a public repo. Credentials are stored in the iOS Keychain.

Clone it locally

Tap the repo in GitSync.md and clone it. GitSync.md writes the files and the full .git directory to your selected Files location. That local working copy is what Obsidian and GitSync.md will share.

2. Open the cloned folder in Obsidian

Open Obsidian on your iPhone or iPad. If you are at the vault picker, choose Open folder as vault. Navigate to the folder GitSync.md cloned, usually inside On My iPhone/iPad → Obsidian, and open it. Not sure where the vault is, or want to move it first? See where your Obsidian vault is stored and how to move it.

Your notes should appear like they do on desktop. If your .obsidian configuration is committed to the repo, themes, snippets, and plugin settings may already be present. If not, configure the mobile vault normally.

3. Configure Obsidian Git for mobile sync

You have two choices. Both use the same local notes, but the app performing Git operations needs its own authentication.

  • GitSync.md handles Git: edit in Obsidian, then use GitSync.md to pull, review, commit, and push. The Obsidian Git plugin is optional for this route. GitSync.md supports its own HTTPS and SSH authentication.
  • Obsidian Git handles Git: install and enable Git by Vinzent in this vault. For GitHub HTTPS repositories using GitSync.md’s GitHub Account authentication, follow the Connect setup tutorial. For manual GitHub credentials, use the Personal Access Token guide. Connect does not add SSH support or change the plugin’s mobile Git implementation.

To hand a Git action to GitSync.md from a note, use its URL scheme. Paste it into a note and tap it, or use an Apple Shortcut. The repo value should match the vault folder name shown in GitSync.md:

syncmd://x-callback-url/sync?repo=MyVault&message=Update%20from%20Obsidian

The sync action pulls first, then stages local changes, commits them with the message you pass, and pushes back to the remote. You can also call individual actions if you want separate buttons:

syncmd://x-callback-url/pull?repo=MyVault
syncmd://x-callback-url/push?repo=MyVault&message=Update%20from%20Obsidian
syncmd://x-callback-url/status?repo=MyVault
Why use the URL scheme?

It lets Obsidian hand the Git operation to GitSync.md, where the local repository, credentials, and libgit2 implementation already live. The link switches apps while GitSync.md performs the operation.

Verify your first pull and push

  1. Create a small test note in the remote repository from another device. Pull with the Git client you chose, then open the note in Obsidian.
  2. Edit that note on your iPhone. Review and commit the change, then push.
  3. Open the remote repository and verify the new commit and exact note contents. If either direction fails, use the Obsidian Git troubleshooting guide before enabling automation.

4. Daily workflow on iPhone and iPad

A good mobile rhythm is simple:

  1. Pull before editing. Tap your syncmd:// pull link, run a Shortcut, or open GitSync.md and pull the vault.
  2. Edit notes in Obsidian. Create daily notes, update project notes, capture inbox items, or work in split view on iPad.
  3. Sync after editing. Trigger the syncmd://x-callback-url/sync URL or use GitSync.md to commit and push.
  4. Review changes when needed. Open the repo in GitSync.md to inspect changed files, branch state, diffs, conflicts, tags, or stashes before pushing.

On iPad, the same setup works with more room: keep Obsidian and GitSync.md side by side, write in Obsidian, then glance at GitSync.md's repo view before pushing.

GitHub and self-hosted remotes both work

GitHub is the fastest setup because GitSync.md can browse your account repositories after sign-in. Self-hosted Git is still supported: paste the remote URL manually, choose HTTPS token/password or SSH private key, and clone into the same Obsidian Files location.

After the repository exists locally, Obsidian does not need to know whether the remote is GitHub, GitLab, Gitea, Bitbucket, or a private server. It edits files in the local vault folder; GitSync.md handles the remote protocol when you sync. For GitLab tokens, scopes and host-key checks, see Sync Obsidian with GitLab on iPhone, iPad and Android.

Troubleshooting

For a symptom checklist covering authentication, missing vaults, conflicts, and delayed automation, see Obsidian Git not working on iPhone.

Obsidian does not show the vault

Check where the repo was cloned. For the easiest Obsidian workflow, clone into On My iPhone/iPad → Obsidian, then use Open folder as vault from Obsidian's vault picker.

Obsidian Git says there is no Git repository

Make sure you opened the cloned repository folder, not its parent folder. The folder you open should contain the hidden .git directory that GitSync.md created.

Push fails from mobile

Open GitSync.md and verify the repo can pull or push there. If GitSync.md cannot authenticate, update the repository's auth method or token. For self-hosted SSH remotes, confirm the private key, passphrase, host, and port.

The sync URL does not find the repo

The repo query parameter must match the vault folder name in GitSync.md. If your folder is named second-brain, use repo=second-brain, not the remote repository title from your Git host.

FAQ

Does Obsidian Git work on iOS?

Yes, with mobile limits. The plugin’s docs say the mobile Git implementation is very unstable, doesn’t support SSH, and limits repository size by memory. See the options table for alternatives.

Do I need Working Copy for Obsidian Git on iPhone?

No. You can use the plugin alone, GitSync.md, Working Copy, a terminal app such as a-Shell or iSH, or an in-Obsidian sync plugin. The options table compares them.

Can I use SSH for Obsidian Git on iOS?

Not in the plugin: its mobile documentation says SSH authentication is not supported. GitSync.md supports SSH private keys for remotes it clones itself; see self-hosted Git over SSH on iOS.

Does it sync automatically in the background?

Don’t count on it. iOS decides when background work runs, so treat sync as something you trigger. How background Git sync works on iPhone explains what to expect.

Is it free?

The Obsidian Git plugin is free. GitSync.md costs $9.99 once on the US App Store, with no subscription. Compare costs with the Obsidian sync cost calculator.

Recap

Obsidian Git on iPhone and iPad works best when you separate responsibilities: Obsidian edits Markdown, GitSync.md owns the real local Git working copy, and iOS Files is the bridge between them. Clone once, open the folder as a vault, then use syncmd:// automation or GitSync.md's own controls to pull, commit, and push.
