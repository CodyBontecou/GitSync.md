Obsidian iCloud sync: set it up and fix it.

Short answer
  1. iCloud works for Apple-only setups: Mac, iPhone and iPad.

Short answer

Obsidian's sync guide says iCloud can sync vaults between iOS and macOS. It also warns that iCloud Drive on Windows may lead to file duplication or corruption. Most "iCloud isn't syncing" problems come from four causes, covered in the checklist: the vault is in the wrong folder on iPhone or iPad, iCloud has offloaded the files, a second service is syncing the same vault, or a Windows PC is involved. If you're still choosing a method, read iCloud vs Git for Obsidian.

Before you start: turn on iCloud Drive

  • Mac: System Settings → your Apple ID → iCloud, and turn on iCloud Drive.
  • iPhone or iPad: Settings → your name → iCloud, and turn on iCloud Drive.

Create an iCloud vault on iPhone or iPad

  1. In Obsidian, choose Create new vault.
  2. Enter a name.
  3. Turn on Store in iCloud.
  4. Tap Create.

Create or open the vault on a Mac

To create a new vault on a Mac: choose Create new vault, pick a location in iCloud Drive → Obsidian in the file picker, name the new folder, and choose Create.

To open a vault that already exists in iCloud on another Apple device, open the vault switcher, choose Open folder as vault, and browse to iCloud Drive → Obsidian.

Keep the vault downloaded

Obsidian recommends keeping the vault folder downloaded. If iCloud offloads files to save space, Obsidian can't access them and you get sync issues.

  • macOS 15 (Sequoia) and later: in Finder, right-click the Obsidian folder in iCloud Drive and choose Keep Downloaded.
  • macOS 14 (Sonoma) and earlier: turn off Optimize Mac Storage in the iCloud settings. This setting affects all iCloud storage on that Mac, not just Obsidian.

Fix: notes or vault not showing up

Before you change anything, make a copy of the vault. Back up an Obsidian vault with Git shows one way. Then work through these in order.

  1. Is the vault in the right folder? (iPhone and iPad) Open the Files app, tap Browse, then iCloud Drive. The vault must be inside the folder with the Obsidian icon. Obsidian says not to use a plain folder without the app icon, and that a vault in a different location may have syncing issues. See where your Obsidian vault is stored and how to move it.
  2. Has iCloud offloaded the files? Files that exist only in the cloud can't be read by Obsidian. Download them, then set Keep Downloaded or turn off Optimize Mac Storage as described above.
  3. Is another service syncing this vault? Obsidian advises against syncing the same vault with multiple services, for example Obsidian Sync and iCloud together, to avoid data conflicts or corruption. Choose one.
  4. Is a Windows PC using iCloud for this vault? Obsidian warns this may lead to file duplication or corruption. Take Windows out of the iCloud setup.

When iCloud isn't the right fit

Windows, Linux or Android in the mix. The iCloud route above covers iOS and macOS. For a Windows PC and an iPhone, see sync Obsidian between Windows and iPhone with GitHub. For Android, see Obsidian Git on Android.

You want history you can restore from. Git keeps commits you can go back to. iCloud vs Git for Obsidian compares the two, and Obsidian Sync alternatives covers the other options.

Move an iCloud vault to Git (summary)

  1. Work in a separate copy of the vault, as iCloud vs Git for Obsidian describes. Make sure every file in the copy is downloaded first.
  2. Put that copy in a Git repository and push it to your Git host.
  3. Clone the repository into a local Files location Obsidian can open, using GitSync.md. The full steps are in Obsidian Git on iPhone and iPad.

Don't keep the same vault in both iCloud and Git sync.

FAQ

Is Obsidian iCloud sync free?

It uses your iCloud storage plan rather than a separate Obsidian subscription. Obsidian's sync guide doesn't give prices, and neither does this page.

Can I use iCloud with Windows?

Obsidian warns that iCloud Drive on Windows may lead to file duplication or corruption. If a Windows PC is in the mix, a different method is safer, such as Git.

Why does my iPhone vault not appear on my Mac?

Open the vault switcher on the Mac, choose Open folder as vault, and browse to iCloud Drive, then Obsidian. If it still isn't there, check on the iPhone in the Files app that the vault is inside the Obsidian folder with the app icon, then see the checklist above.

Can I use iCloud and Obsidian Sync together?

Obsidian advises against syncing the same vault with multiple services, for example Obsidian Sync and iCloud together, because it can cause data conflicts or corruption. Pick one per vault.
