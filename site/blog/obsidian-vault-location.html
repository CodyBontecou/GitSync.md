Where your Obsidian vault is stored and how to move it.

A vault is an ordinary folder you chose. This guide shows where to find it on desktop, iPhone, iPad and Android, how to move, rename or remove it, and how to move a vault that is a Git repository without losing the hidden folders.

Short answer

Obsidian does not store your notes in a database. A vault is an ordinary folder that you chose when you created or opened it, and your notes are plain files in it. Inside that folder, .obsidian holds the preferences for that vault, such as hotkeys, themes and community plugins. The list of vaults Obsidian knows about is kept elsewhere, in a global settings folder on desktop (see the table below). That is why a vault can sit anywhere, and why moving the folder by hand can leave Obsidian pointing at the old place until you open the new one.

The examples use a made-up vault called second-brain.

The example folders on desktop are only examples. Obsidian puts a vault wherever you told it to.

Find the exact path from inside Obsidian. Open Manage vaults from the vault profile menu at the bottom left to see your vault list. On desktop, you can also right-click a file in the file explorer and choose the option that reveals it in Finder or File Explorer. On a phone, the Files app shows iPhone and iPad vaults directly; on Android, the vault is in the folder you picked.

Show hidden folders

.obsidian and .git start with a period, so most file managers hide them. You need to see them when you move a Git vault.

  • macOS Finder: press Cmd+Shift+. to show or hide hidden files.
  • Windows File Explorer: use View and turn on Hidden items.
  • Linux: most file managers have a "show hidden files" option; in a terminal, ls -a lists them.

Move a vault on desktop

Follow Obsidian's order:

  1. Open Manage vaults from the vault profile menu at the bottom left.
  2. Close the current vault window and leave the Manage vaults window open.
  3. In the vault list, select More options next to second-brain, choose Move vault, then pick the new location.

Obsidian warns that some operating systems do not allow a vault to be moved with the vault switcher. If yours doesn't, use the manual way:

  1. Close Obsidian.
  2. Move the second-brain folder to the new location in your file manager.
  3. Reopen Obsidian, open Manage vaults, and next to Open folder as vault click Open.
  4. Select the moved folder and click Open. Check that the vault contents are unchanged.

Afterwards, check that your plugins are still on. If community plugins are off, go to Settings → Community plugins and turn restricted mode off.

Where not to put it. Move the vault to a place that no other sync service manages; Obsidian tells you to avoid folders synced by other services. And don't put a vault in Obsidian's global settings folder, because that may lead to corrupted data or data loss.

Rename and remove a vault

  • Rename: the vault name and the folder name are the same thing, so renaming a vault also renames the folder. In Manage vaults, choose More options → Rename vault, type the new name and press Enter.
  • Remove: More options → Remove from list only removes the vault from the list. The files stay where they are, and you can add the folder again with Open folder as vault.

Move a vault to another computer

Copy the whole second-brain folder to the other computer, including hidden folders, then open it there with Open folder as vault. Copying only the notes leaves your settings behind.

A better way, if you want the vault on more than one machine, is to make it a Git repository and clone it on the new computer. You get history, and the same repository can be cloned on a phone. See how to sync Obsidian with GitHub, and back up an Obsidian vault with Git for the backup side.

iPhone and iPad: local vs iCloud vaults

Which one do you have?

Open the Files app and tap Browse. A local vault is a folder inside On My iPhone (or On My iPad) → Obsidian. An iCloud vault is inside iCloud Drive → Obsidian. Obsidian's sync guide says an iCloud vault should be at iCloud Drive/Obsidian/[Your Vault Name], inside the Obsidian folder that has the app icon, not in a plain folder with the same name. When you create a vault in the app, the Store in iCloud toggle decides which one you get.

Why a vault you copied in doesn't show up

Obsidian only offers vaults that sit in a folder it can open. A folder copied somewhere else in Files won't appear in the vault picker. Put it in the Obsidian folder, or in the vault picker choose Open folder as vault and browse to it.

Move a vault from iCloud Drive to On My iPhone

  1. In the Files app, open iCloud Drive → Obsidian. Files that show a cloud icon are not on the phone yet; download them first by tapping them, and wait until nothing is waiting to download. A copy of placeholder files is not a copy of your notes.
  2. Touch and hold the second-brain folder, choose Move (or Copy to be safe), and pick On My iPhone → Obsidian.
  3. Open Obsidian, choose Open folder as vault in the vault picker, and select the moved folder.
  4. Check a few notes, then delete the iCloud copy only once you're sure nothing is missing.

Then sync the local vault with Git

A local vault does not sync by itself. With GitSync.md you can put it in a Git repository. The steps match the Obsidian Git on iPhone and iPad guide:

  1. Commit and push the vault to a remote repository first, from a computer or from GitSync.md's publish flow.
  2. In GitSync.md, set the save location to On My iPhone/iPad → Obsidian and clone the repository.
  3. In Obsidian, choose Open folder as vault and open the cloned folder.

If you cloned into the same place as the copied vault, remove or rename one of them so there is only one working copy. For the trade-offs, see iCloud vs Git for Obsidian.

Android

On Android, a vault is the folder you picked when you created or opened it, and where that is differs by device. Obsidian's help pages don't give a fixed path, so check the vault's folder from inside the app rather than guessing. To use an existing folder, use Open folder as vault and select it.

To keep that vault in a Git repository, see Obsidian Git on Android. GitSync.md is on Google Play; the same guide explains that the repository folder and Obsidian's vault must be the same folder in shared storage.

Move a Git-backed vault safely

  1. Commit and push first. That gives you a copy on the remote before you touch anything.
  2. Move the whole repo folder. Include .git (your history and remote settings) and .obsidian (your vault settings). Show hidden folders first, and don't copy only the notes.
  3. Check the working tree afterwards. On desktop, run git status in the moved folder. It should report nothing to commit, working tree clean. See git status. On a phone, check the repository's status in GitSync.md.
  4. Don't create a second clone inside the old folder. Two working copies of one vault cause duplicate notes and confusion about which one Obsidian has open.
  5. Ignore workspace.json. Obsidian rewrites .obsidian/workspace.json whenever you open a file, so it shows up as a change every time. See the Obsidian .gitignore guide or the .gitignore generator.

On a phone, the safest route to a new location is to push, then clone the repository again into the folder you want, as described above, rather than dragging a repository around in Files.

Troubleshooting

  • Vault missing from the picker. Use Open folder as vault and select the folder. Make sure you pick the vault root, the folder that holds .obsidian, not its parent.
  • Plugins are off after a move. Go to Settings → Community plugins and turn restricted mode off. If .obsidian didn't come along, reinstall them.
  • iCloud vault not detected, or files not downloaded. In Files, check the vault is inside iCloud Drive → Obsidian, in the folder with the Obsidian icon. Tap files with a cloud icon to download them. If it still fails, move the vault to On My iPhone → Obsidian as above.
  • Duplicate vault after a move. You probably have the old and new folders in the list. Remove the old one with More options → Remove from list; that keeps the files. Then check which folder still has your latest notes before you delete anything.
  • Git can't find the repository. The hidden .git folder didn't move with the notes. See Obsidian Git not working on iPhone.

FAQ

Where is my Obsidian vault?
In the folder you chose when you created or opened it. Open Manage vaults to see your vaults. On iPhone, look in the Files app under On My iPhone or iCloud Drive.

Does Remove vault delete my notes?
No. It only removes the vault from the list, and the files stay in the folder.

Where does Obsidian keep its global settings?
On macOS, ~/Library/Application Support/obsidian; on Windows, %APPDATA%\Obsidian\; on Linux, $XDG_CONFIG_HOME/obsidian/ or ~/.config/obsidian/.

Can I move a vault into a Dropbox or iCloud folder on desktop?
Obsidian advises against folders synced by other services when you move a vault. Git is a cleaner way to sync.

Do I need the .obsidian folder?
It holds that vault's hotkeys, themes and plugins. Without it your notes are fine, but your settings are gone.
