Short answer

On Windows and Mac you can open a vault stored in a Google Drive folder. On Android it can work. On iPhone and iPad Obsidian doesn't officially support Google Drive, Dropbox or OneDrive vaults. If you need one vault on a phone and a computer, pick one of the routes below, and use only one sync method per vault.

Short answer: does Obsidian work with Google Drive?

It depends on the device. Source: Obsidian Help: Sync your notes across devices (checked 2026-11-23).

Why it works on desktop and not on iPhone

A desktop vault is just a folder, and any program that syncs folders can sit underneath it. On iPhone and iPad, Obsidian opens vaults stored on the device or in iCloud. Obsidian's help page recommends Obsidian Sync and iCloud on iOS and says: “Google Drive is not officially supported for syncing Obsidian vaults on iOS.” It describes Dropbox, OneDrive and Syncthing the same way and points to plugins such as Remotely Save or LiveSync as workarounds that “aren't officially supported, and results may vary.” (Obsidian Help: Sync your notes across devices, checked 2026-11-23.)

If Syncthing is the tool you already run, see Obsidian with Syncthing on iPhone and iPad.

The same page says OneDrive has limitations on Android and advises avoiding OneDrive's Files On-Demand feature for vaults.

Option: Remotely Save with Google Drive, Dropbox or OneDrive

The Remotely Save README (checked 2026-11-23) lists Amazon S3 or S3-compatible storage, Dropbox, OneDrive for personal (App Folder), WebDAV and Webdis as free. Google Drive, OneDrive for personal (Full), Box, pCloud, Yandex Disk, Koofr and Azure Blob Storage are marked PRO features. It supports Obsidian Mobile, and it says auto sync only works when Obsidian is open. That's the main trade-off: nothing syncs while Obsidian is closed. For how it compares with other plugins and services, including Dropbox and OneDrive, see Obsidian Sync alternatives.

Option: Android folder-sync apps

On Android the vault lives in a normal folder, so a folder-sync app such as Autosync or FolderSync can mirror a local phone folder with a Google Drive folder, while Google Drive for desktop mirrors the same Drive folder to your computer. Pricing, schedule and conflict handling differ per app, so read the app's own page. The vault should still be opened by Obsidian from the local folder, not from Drive itself. This route is Android only; iPhone has no equivalent.

Option: Sync the vault with Git instead

Git keeps a commit history of every note, works with a private repository, and has setup guides for each device. GitSync.md is a Git client for iPhone, iPad and Android; on desktop you use Git or the Obsidian Git plugin. The trade-off is that you push and pull yourself rather than having a service run silently. Don't run two syncs on one vault

  • Use exactly one sync method per vault.
  • Don't put a Git working copy inside a Google Drive, OneDrive or Dropbox synced folder. Two tools rewriting the same files cause duplicates and conflicts, as the GitHub sync guide also says.
  • GitSync.md on Android refuses cloud folders. In the app's words: “Phone storage and SD cards work. Cloud folders such as Google Drive can’t hold a Git repository.” See Obsidian Git on Android.
  • For a Drive copy, make it one-way. A scheduled zip or export of the vault folder is a backup, not a second sync. For the Git version, read backing up an Obsidian vault with Git.

Move a vault from Google Drive to Git

  1. Copy the vault folder to a local, non-synced folder.
  2. Stop Drive syncing the old location.
  3. Open the new folder in Obsidian and confirm all your notes are there.
  4. Create a private repository: see creating a Git repository or the GitHub sync guide.
  5. Add a .gitignore with the Obsidian .gitignore generator.
  6. Clone the vault on your phone with GitSync.md.
  7. Make a two-way test edit: change a note on each device and confirm both appear on the other after sync.

FAQ

Can I open a Google Drive vault in Obsidian on iPhone?

Not officially. Obsidian's help page says Google Drive is not officially supported for syncing vaults on iOS. The iOS app opens vaults stored on the device or in iCloud, and any Drive workaround relies on plugins or other tools whose results may vary.

Is Remotely Save Google Drive free?

No. The Remotely Save README marks Google Drive as a PRO feature. Dropbox, OneDrive for personal (App Folder), S3-compatible storage, WebDAV and Webdis are listed as free.

Can I keep my vault in OneDrive on Windows and use it on iPhone?

Obsidian's help page says OneDrive isn't officially supported on iOS and has limitations on Android. On Windows the vault itself can sit in OneDrive, but to reach it on iPhone you need a different route, such as Remotely Save with the OneDrive App Folder, iCloud, Obsidian Sync, or Git.

Will Git work with my existing Google Drive vault folder?

Copy the vault to a normal local folder first. A Git working copy shouldn't live inside a Drive, OneDrive or Dropbox synced folder, because two tools would rewrite the same files. See the move checklist above.
